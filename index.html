카메라 설정

운영자용이에요. 자판기 카메라 스트림 주소를 연결해요.

Cloudflare Tunnel에 연결된 실제 MJPEG 엔드포인트를 입력해요. 예시 주소는 실제 서버가 아니에요.

주소는 이 브라우저에만 저장돼요. 모든 방문자에게 적용하려면 Cloudflare의 VITE_CAMERA_STREAM_URL에 등록한 뒤 다시 배포해 주세요. 비밀번호나 API 토큰은 주소에 넣지 말고, 운영 전에 학교의 CCTV 설치·공개 및 접근 권한 기준을 꼭 확인해 주세요.
